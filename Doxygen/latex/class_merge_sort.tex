class Merge\+Sort$<$ T $>$}
Klasa szablonowa implementująca algorytm sortowania przez scalanie (\doxylink{class_merge_sort}{Merge\+Sort}). 

Algorytm działa w oparciu o paradygmat „dziel i zwyciężaj” ze złożonością czasową $O(n \log n)$ oraz pamięciową $O(n)$.
