Detailed Description

template<typename T>
class MergeSort< T >

Klasa szablonowa implementująca algorytm sortowania przez scalanie (MergeSort).

Algorytm działa w oparciu o paradygmat „dziel i zwyciężaj” ze złożonością czasową oraz pamięciową .

Template Parameters
TTyp elementów przechowywanych w tablicy (musi obsługiwać operator porównania <=).

Scala dwie posortowane podtablice w jedną uporządkowaną całość.

Funkcja dzieli rozpatrywany fragment tablicy na dwie tablice pomocnicze (lewą i prawą), a następnie przepisuje elementy z powrotem do tablicy głównej w kolejności niemalejącej.
